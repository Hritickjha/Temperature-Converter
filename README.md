#####################################
#   Temperature Converter     #
#####################################

This repository contains a temperature converter tool that allows users to convert temperatures between Celsius and Fahrenheit.

To use the converter:
- Input a temperature in either Celsius or Fahrenheit.
- Click the 'Convert' button to see the temperature in the other unit.

This tool is designed to be simple and easy to use for basic temperature conversions.
